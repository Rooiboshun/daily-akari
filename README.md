# daily-akari

美術館パズル（Akari / Light Up）の日替わり版。

ソルバ・一意解ジェネレータ・遊ぶ画面まで入っています。依存パッケージもビルドも
無く、`index.html` を置くだけで動きます。
実装されているものの一覧は [docs/FEATURES.md](docs/FEATURES.md) にあります。

## ルール

白マスに照明を置きます。

1. 照明は自分のマスと上下左右を、黒マスか盤の端に当たるまで照らす
2. 照明どうしが照らし合ってはいけない
3. 数字の入った黒マスは、上下左右に接する照明の数がその数字とちょうど一致する
4. すべての白マスが照らされている

## 面白いのは「作る」側

解くソルバは制約伝播＋バックトラックで素直に書けます。手間がかかるのは
**解が必ず1つに定まる盤面を作る**ほうで、こういう手順にしています。

1. 黒マスを 180 度回転対称に配置する
2. 白マスを全部照らす照明配置をランダムに1つ作る（完成形）
3. すべての黒マスに、その配置から計算した数字を入れる
4. 数字を1つずつ外していき、外すたびにソルバで「まだ解が一意か」を検査する。
   一意でなくなるなら外さない

4 は1周で済みます。数字を外して解が増えることはあっても減ることはないので、
一度外せなかった数字は後からも外せないためです。結果として
「どの数字を1つ外しても一意でなくなる」極小の問題になります。

## 日替わりにサーバは要らない

日付そのものを乱数の種にすると、生成が決定的になります。
`2026-09-20` から作られる問題は、誰がいつどの端末で開いても同じものです。
だから問題を配信するサーバも、問題を貯める DB も要りません。
HTML1枚を GitHub Pages に置くだけで「毎日同じ問題が全員に出る」が成立します。

## 使い方

Node 18 以上。依存パッケージはありません。

```sh
npm run serve                        # http://127.0.0.1:8123/ で遊ぶ
npm run serve -- 8123 /daily-akari/  # サブパスへ公開した状態を再現する
npm run verify                       # ソルバと生成器の検証を全部回す
npm run uitest                       # 画面の検証（ヘッドレス Chrome を使う）
npm run peek                         # 今日の問題 (normal)
npm run peek -- 2026-09-20 hard -a   # 日付・難易度を指定して、答えも表示
```

ES モジュールは `file://` では読めないので、手元で開くときは `npm run serve` を
挟みます（GitHub Pages では不要）。

遊び方は、白マスをクリックで照明、右クリック（スマホは長押し）で「置かない」印。
点灯・照らし合い・数字の達成はその場で色が付き、4つのルールを全部満たすと
クリアになります。途中経過は日付と難易度ごとにブラウザへ保存されます。

盤面ロジックだけを使いたいときは、同じファイルをそのまま読めます。

```html
<script type="module">
  import { dailyPuzzle, todayString, render } from './src/akari.js';
  const { puzzle, solution } = dailyPuzzle(todayString(), 'normal');
  console.log(render(puzzle));
</script>
```

## 難易度

| | 大きさ | 試行錯誤 |
| --- | --- | --- |
| `easy` | 7x7 | 要らない（制約伝播だけで解ける） |
| `normal` | 9x9 | 要らない |
| `hard` | 10x10 | 要ることが多い |

`easy` と `normal` は「分岐なしで解ける問題だけ」を作るようにしているので、
詰まったら必ずどこかに見落とした確定マスがあります。
